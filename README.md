# KPI MTTQ (độc lập)

## Chạy
- Mở bằng Live Server (VS Code) hoặc `npx serve .`, vào `index.html`.

## Config Supabase
- Sửa `js/config.js`: `SUPABASE_URL` + `SUPABASE_KEY` (anon key).
- Chạy `supabase/schema.sql` trong Supabase SQL Editor để tạo 3 bảng.

## Token demo
- Admin: `ADM-MAUA-adm` (full).
- `CQ-MAUA-TVH1-MTTQ` (mttqAdmin, full MTTQ).
- 9 token staff còn lại `CQ-MAUA-...-MTTQ`: chỉ sửa/xóa nhiệm vụ đúng tên mình, được thêm mới.
